# XAU Trend Radar (มือถือ)

แอปวิเคราะห์เทรนด์ทอง D/H4/H1 และโซนกลับตัว M15 แบบ PWA ใช้ได้ทั้ง iPhone และ Android ไม่ต้องมี server

- **แท่งเทียน:** Twelve Data (XAU/USD) ต้องใช้ API key ฟรีของตัวเอง กรอกในหน้า ⚙️ ตั้งค่า (เก็บไว้ในเครื่องเท่านั้น)
- **ราคาสด:** gold-api.com
- **บันได B / forward test:** เก็บใน localStorage ของเครื่อง
- **แจ้งเตือน:** ทำงานเฉพาะตอนเปิดแอปไว้

## ติดตั้งบนมือถือ
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" → เปิดแอปจากไอคอน แล้วกด 🔔 (iOS 16.4 ขึ้นไป)
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

## แก้ไข
ไฟล์ `index.html` สร้างจาก `Trend-App/index.html` ด้วย `python Trend-App/mobile_build.py` ให้แก้ engine ที่แอป PC แล้ว build ใหม่ ห้ามแก้ไฟล์นี้ตรงๆ
ถ้าเปลี่ยน `index.html` ให้เพิ่มเลขเวอร์ชัน `CACHE` ใน `sw.js` ด้วย มือถือจะได้โหลดของใหม่

⚠️ เป็นเครื่องมือช่วยวิเคราะห์ ไม่ใช่คำแนะนำการลงทุน กฎของระบบผ่าน backtest แบบมีข้อจำกัด และฝั่ง Sell ยังเป็นสมมติฐาน
